# Product Overview

SKyMed is an emergency medical drone delivery system that provides real-time monitoring and management of medical supply deliveries via autonomous drones.

## Core Features
- **Parcel Management**: Send and track medical parcels through drone delivery
- **Real-time Monitoring**: Live map tracking of active drones and deliveries
- **Emergency Response**: Critical delivery prioritization and alert systems
- **Fleet Management**: Monitor drone status, battery levels, and operational metrics
- **Analytics Dashboard**: Performance metrics, success rates, and delivery analytics

## User Types
- **End Users**: Send parcels, track deliveries, view personal dashboard
- **Operations Team**: Monitor fleet, manage routes, handle emergencies
- **Administrators**: System configuration, user management, analytics

## Key Metrics
- Delivery success rate (target: 98%+)
- Average delivery time (target: <15 minutes)
- Fleet utilization and availability
- Emergency response times
